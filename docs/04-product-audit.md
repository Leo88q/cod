## 2. Сквозные сценарии (4 роли)

**А. Даритель (основной)**
Бот → «Создать подарок» → вводит кому/повод → подбирает 5–7 сцен по тегам → пишет сообщение/прикрепляет фото → выбирает «одна сцена» или «серия на 3 дня» → ставит дату открытия (напр., 8 марта в 00:00) → получает ссылку + QR → отправляет в чат или вкладывает карточку в букет. Если букет ещё не куплен — на странице подарка блок «Добавить букет» → выбирает город получателя и букет → переходит на Flowwow по партнёрской ссылке → заказывает. Ref заказа привязан к подарку.

**Б. Получатель**
Открывает ссылку/сканирует QR → lock-экран с обратным отсчётом, если дата не наступила → анимированная открытка: фильм, таймкод, «смотреть» (Кинопоиск/Иви/Okko/YouTube; если проверен прямой watch_url — сразу с позиции) → сообщение дарителя → отвечает: эмодзи, своей сценой из каталога или текстом → даритель получает уведомление в боте → оба видят общий таймлайн. Может добавить заметку/фото к моменту.

**В. Цветочная студия (B2B)**
Подключается по агентскому договору → получает QR-карточки (пачками за оплату или подпиской 990 ₽/мес) → вкладывает в букеты → видит в кабинете: сканов, созданных подарков, заказов по ref, начисленную комиссию → подтверждает заказы по id Flowwow → получает выплаты по акту.

**Г. Админ**
Модерирует предложенные сцены, сверяет таймкоды (очередь unverified), смотрит overview и выручку.

## 3. «Будет ли интересно людям» — разбор

### Почему это может зайти (инсайты)
1. **Сцена вместо открытки = персонализация без усилий.** «С 8 марта» — шаблон. Ссылка на конкретный момент фильма + «это напомнило мне о нас» — личное. Мы даём «слова», которых у человека не было.
2. **Кино — общий язык пары/семьи.** У двоих есть «их» фильмы; таймлайн собирает историю из общих точек.
3. **Ответ сценой — социальный долг, который приятно отдать.** Получатель не «должен ответить», но хочется — это виральная петля: каждый подарок рождает ответ, а ответ — новый повод.
4. **Физический мост (QR в букете)** — букет уже дарят, мы добавляем цифровой слой «второго подарка» без изменения привычки.
5. **Серия на дни + отложенное открытие** — повод возвращаться (retention), а не one-shot.
6. **«Ваш фильм года»** — экспортируемый артефакт для шаринга в соцсетях (бесплатный маркетинг).

### Виральные петли (k-factor)
- Получатель отвечает сценой → у обоих растёт таймлайн → оба хотят продолжать.
- Шаринг «вашего фильма» в конце года → приток новых пар.
- QR-карточка в букете → скан → создание подарка (новый пользователь-даритель).
- Напоминания о датах → повторные подарки (LTV).

### Слабые места и чем закрывать
| Риск | Почему больно | Митигация |
|---|---|---|
| Таймкод не совпал / плеер не тот | «магия» ломается | очередь верификации (admin `/verify`), хранить service+version, прямой watch_url где возможно, fallback «перемотай на X» |
| Friction внешнего плеера | лишние клики | deep links (YouTube `t=`, если найдём надёжные), «скопировать таймкод» одной кнопкой |
| Каталог мал (60 сцен, unverified) | мало «попаданий» под повод | импорт CSV, пользовательские предложения, сверка; цель 200–300 verified |
| Аудитория — только Telegram | потолок | второй клиент под MAX на том же бэкенде (запланировано) |
| B2B-продажа студиям — длинный цикл | кэш сгорает | пилот 5–10 студий в одном городе, бесплатные первые 100 карточек |
| Приватность | доверие | мы не храним телефоны получателей; согласия в `consents`, 152-ФЗ |

### Метрики и гипотезы
- North star: число пар с ≥1 взаимным ответом сценой в месяц.
- Activation: % подарков, открытых в течение 24 ч (цель ≥ 60%).
- Virality: k = ответы-сценой / созданные подарки (цель ≥ 0.3).
- B2B: сканов карточек → созданных подарков (≥ 30%), CTR букета со страницы подарка (≥ 5%), подтверждённых заказов на студию.
- Деньги: комиссия на студию в месяц, ARPU премиума.

### Чего не хватает (gap → приоритет)
1. Город получателя не подхватывается автоматически в букеты → добавить `recipient_city` в подарок (сделаю сейчас).
2. После ответа нет явного приглашения «ответить подарком» → виральная петля (сделаю сейчас).
3. Подтверждение заказа букета у студии (атрибуция комиссии) — ручной ввод id заказа Flowwow в кабинете (сделаю сейчас).
4. Deep links плееров с таймкодом (YouTube `?t=`, проверка Иви/Okko/Кинопоиска) — ручная проверка, потом `watch_url`.
5. MAX-клиент, push-уведомления вне Telegram (email/SMS) — позже.
6. A/B: «сцена-first» vs «букет-first» в воронке заказа.

## 4. Вывод
Интерес будет, если сходятся три вещи: (а) таймкоды реально работают (верификация), (б) каталог достаточно широкий под поводы, (в) букет+QR даёт B2B-канал привлечения, а ответ-сценой — виральность. Деньги — не в «продаже сцен», а в комиссии с букетов, карточках студиям и премиуме.
