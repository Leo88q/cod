# 18. Как куратору отбирать таймкоды: где время и где ссылки

Экран: `http://localhost:8000/app/#/admin`, токен `local-admin` → «Сохранить» → «Загрузить». Первым открывается **одна компактная таблица на 50 строк** «💘 Признание в любви и чувства». Карточек, фильтров, сводных таблиц таймкодов, бейджей и инструкций «найди момент сам» больше нет; служебные очереди свёрнуты в закрытый `<details>` внизу страницы.

## Что в таблице

| Колонка | Что лежит | Можно менять |
|---|---|---|
| `#` | порядок в блоке (1–50) | нет |
| `Фильм` | название и год | нет |
| `Ссылка на фильм` | **точная прямая ссылка VK Видео / Rutube на полный фильм** — для 9 фильмов, у остальных 41 пустое поле | да |
| `Начало` / `Конец` | подготовленный отрезок, `0:43:04` … `1:37:30` | да |
| `Версия издания` | пусто до проверки; обязательна для «✓» | да |
| `Проверка` | статус `к проверке` / `проверено` / `отклонено` и кнопки | действия |

Под таблицей одна строка со сводкой: `50 фильмов · 9 прямых ссылок VK/Rutube · 41 полей под ссылку · проверено: 0 · version_note обязателен`.

**Откуда время.** 13 окон подтверждены локальными SRT, 13 — внешние ориентиры (Clip.Cafe и подборки цитат), 24 — уникальные начальные ориентиры. У всех 50 строк разный старт, конец ограничен реальной длительностью фильма. Ни одна строка не считается проверенной: `verified=0`, `verified_by_human=false`, статус `pending`.

**Откуда ссылки.** Только точные ID официальных бесплатных полных версий из `data/timecode_library/official_free_videos.json` (источник `rutube_russia1`): Афоня, Война и мир, Ирония судьбы, Кавказская пленница, Курьер, Любовь и голуби, Москва слезам не верит, Служебный роман, Чародеи. Для остальных фильмов точного ID нет, поэтому поле **пустое и редактируемое** — поисковые URL `vkvideo.ru/search?…` и «Мосфильм»-префиксы к чужим фильмам не подставляются. Если куратор нашёл легальную полную версию, он вставляет прямую ссылку VK/Rutube в поле сам.

## Порядок работы со строкой

1. **«▶ Проверить»** открывает прямую ссылку с таймкодом: VK Видео получает `?t=<секунды>s`, Rutube — `?t=<секунды>`. С пустым полем кнопка попросит вставить ссылку.
2. Посмотри отрезок в плеере, при необходимости поправь **Начало/Конец** и **Ссылку на фильм**, впиши **Версию издания** (издание/реставрация может сдвинуть минуты).
3. **«💾»** сохраняет строку через `POST /api/admin/moderation/love-confession/{candidate_id}/edit`. Это черновик: `verified` остаётся `0`, сцена пользователям не меняется.
4. **«✓»** подтверждает через `POST /api/admin/moderation/confirm`: без `version_note` вернёт 400, после успеха `verified=1`, строка станет `проверено`, а `watch_url` сцены получит deep link `?t=`.
5. **«✗»** отклоняет строку (`status=rejected`), не трогая сцену.

Сохранить и подтвердить — разные действия. Ручной просмотр и версия издания обязательны; авто-одобрения нет.

## Что под капотом

- `GET /api/admin/moderation/love-confession/table` — 50 строк: `film_url`, `film_link_kind` (`direct` / `empty`), таймкоды, `version_note`, `status`. Поисковых URL в ответе нет. `GET /api/admin/moderation/love-confession` — совместимый алиас с тем же ответом.
- `POST /api/admin/moderation/love-confession/{candidate_id}/edit` — таймкоды, прямая ссылка и версия издания пишутся в строку блока (`timecode_candidates.film_url`, `version_note`), `verified` не меняется; ссылка принимается только на `vkvideo.ru` / `vk.com` / `vk.ru` / `rutube.ru` с путём `/video…`, параметры `t/start/end` вырезаются.
- `POST /api/admin/moderation/confirm` — единственное место, где ставится `verified=1`; обязателен `version_note`, `watch_url` нормализуется в deep link.
- Данные блока пересобираются `scripts/build_love_confession_batch.py --write`; он же генерирует [20-love-confession-batch.md](20-love-confession-batch.md). Текст субтитров не сохраняется: только время, sha1, источник, лицензия и кураторский контекст.
