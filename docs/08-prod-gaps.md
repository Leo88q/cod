## Общие квоты API (реализовано)

- `RATE_LIMIT_PER_MIN=60`: все POST `/api/*` с одного IP.
- `RATE_LIMIT_USER_PER_MIN=60`: дополнительная квота проверенного Telegram-пользователя (по умолчанию равна общей).
- `RATE_LIMIT_GIFTS_PER_MIN=10`, `RATE_LIMIT_SUGGEST_PER_MIN=5`: отдельные квоты IP и пользователя.
- ID из тела запроса и неподписанный initData не считаются доверенной идентичностью. IP-квота применяется всегда.
- Счётчики `rate_limit_buckets` хранят SHA-256 идентификаторов, а не исходные IP/ID. Это псевдонимизация, не анонимизация. Старые окна очищаются при следующем запросе.
- Транзакция `BEGIN IMMEDIATE` проверяет и увеличивает все квоты атомарно; отказ не расходует другие квоты. Работа с БД выполняется вне event loop.
- Окно фиксированное (60 секунд): на границе окон возможен краткий двойной всплеск. Это антиспам, не полноценная защита от DDoS.
- Все workers должны использовать один локальный SQLite-файл. Не размещать WAL-БД на сетевой ФС; при горизонтальном масштабировании перейти на Redis.
- За прокси доверять forwarded-заголовкам только от доверенного ingress; публичный доступ напрямую к uvicorn закрыть.
- Проверки: `tests/test_rate_limit.py` — конкурентность, сброс окна, откат квот, подпись Telegram и HTTP 429/Retry-After.

## Подписанные ссылки на медиа (реализовано)

- Прямой StaticFiles-доступ к `/media` удалён. Файлы выдаются только с HMAC-SHA256 подписью имени файла, ID подарка и срока действия.
- `MEDIA_SIGNING_SECRET` обязателен при `ALLOW_ANON=0`; задайте случайный секрет всем workers. В dev без секрета используется случайный ключ процесса (ссылки перестают работать после перезапуска).
- `MEDIA_URL_TTL_SECONDS=900`: 15 минут. Повторное открытие доступной открытки выдаёт свежие ссылки. Долго открытая страница может потребовать обновления для медиа.
- На каждом скачивании проверяется состояние подарка, время открытия и принадлежность файла подарку/его ответам. Удалённые и просроченные подарки не отдают медиа даже по ещё действующей ссылке.
- Ответы файлов: `Cache-Control: private, no-store`, `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`. Разрешены только безопасные имена; symlink за пределы каталога запрещён.
- БД и upload API по-прежнему хранят/возвращают обычный путь, не временную ссылку. Просмотр по этому пути без подписи закрыт.
- Это bearer-ссылка: получатель может переслать её до истечения срока, а скачанный файл отозвать невозможно. URL подарка тоже является секретом доступа. Не логировать query-параметры ссылок на ingress/CDN.
- Не настраивайте nginx/CDN на прямую публичную раздачу каталога `media/`: это обойдёт защиту приложения.
- Проверки: `tests/test_media_access.py` (подмена, истечение, удаление, отложенное открытие, непривязанный файл, symlink).
