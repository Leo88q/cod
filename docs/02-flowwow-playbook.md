# Плейбук интеграции с Flowwow (и агрегаторами цветов) — «Сцена»

Дата: 2026-11-03. Все факты ниже — из открытых источников, проверены 2026-11-03; договорные условия запрашиваем у Flowwow письменно.

## 1. Что такое Flowwow сегодня

- Маркетплейс локальных магазинов цветов и подарков: **16 000+ продавцов, 1 200+ городов, 5+ млн пользователей**.
- Комиссия с магазина за продажу: **5–23%** (зависит от категории и города; цветы в Москве ~20–23%, в регионах 12–16%) + **~3% эквайринг** + **3% кэшбэк клиенту** в категории «цветы и подарки». Выплаты — еженедельно.
- **Zero-commission**: заказы по **прямой ссылке магазина** (например, из его соцсетей) — комиссия за продажу **0%**, только ~3% за эквайринг.
- Открытое API (seller-docs.flowwow.com) — **только для продавцов** (свои товары/заказы). Публичного API «создать заказ как покупатель» **нет**.
- Есть B2B-сегмент «Подарки для бизнеса» (info.flowwow.com/corporate): оплата со счёта компании, договор-оферта, документы в кабинете.
- Контекст рынка 2026: Яндекс пытался купить Flowwow (сделка на 8+ млрд ₽ сорвалась в мае 2026) и запустил **«Яндекс Цветы»** — отдельное приложение. Рынок растёт, конкуренция с экосистемой жёсткая.
- Контакты: partner@flowwow.com, partners@flowwow.ru. Выплаты — на ИП / самозанятых / юрлицо.

## 2. Наши механики поверх Flowwow

### Механика A. QR-карточка «Сцена» в букете (основная, не требует API Flowwow)

1. Студия покупает у нас пачку карточек (или подписку) в своём кабинете.
2. Флорист вкладывает карточку с QR в букет. QR ведёт на `https://<наш-домен>/app?card=<код>`.
3. Получатель сканирует → страница подарка (сцена + сообщение). Darитель создал подарок заранее в Mini App и привязал код карточки, либо создаёт «на лету» по ссылке на карточке.
4. Студия платит нам за карточки/подписку — это наш прямой доход, Flowwow в цепочке не участвует.

### Механика B. Витрина букетов + комиссия (CPS)

1. На странице подарка — блок «добавить букет»: подборка букетов города получателя.
2. Клик → **прямая ссылка магазина на Flowwow** с нашей ref-меткой (utm/referral, обсуждаем с каждой студией).
3. Так как покупатель пришёл по прямой ссылке магазина, Flowwow берёт с магазина 0% комиссии — магазин платит **нам** 10–15% по агентскому договору.
4. Fallback: если у студии нет прямой ссылки — обычная ссылка flowwow.com с utm; тогда commission платит Flowwow по своей партнёрке (если подтвердит нас партнёром) либо не платим вообще — тогда это просто «удобный переход», а зарабатываем на карточке.

### Механика C. Deep link в приложение Flowwow

- Проверить формат deeplink приложения Flowwow на товар/корзину (документации нет — тест руками из приложения: «поделиться» → ссылка).
- Если есть — кнопка «Заказать в приложении Flowwow» открывает товар сразу в их приложении с ref.

## 3. Пилот: 5–10 студий одного города (скрипт)

**Где искать**: каталог магазинов Flowwow в целевом городе (flowwow.com → город), 2ГИС/Яндекс Карты «цветы доставка», Instagram/VK студий с доставкой.

**Холодный заход (DM/звонок, 5 минут)**:
> «Здравствуйте! Мы делаем «Сцену» — карточку с QR, которую можно вложить в букет: получатель сканирует и попадает на личную страницу с escena из фильма, таймкодом и вашим поздравлением — и может ответить своей сценой. Мы печатаем первые 100 карточек бесплатно, вы получаете статистику сканов в кабинете и можете добавить к заказу букет через Flowwow по прямой ссылке — с нас комиссия 10–15% за приведённого клиента, с Flowwow — 0%. хотим piloto на месяц, без обязательств.»

**Что подписываем**: агентский договор (ИП) — commission 10–15% с заказов по нашей ref-ссылке + купля-продажа карточек; поручение на обработку ПДн (мы не видим данные получателей, только факт скана).

**Метрики пилота**: карточек в букетах, сканов, созданных подарков, ответов, заказов букетов по ref, конверсия. Цель пилота: ≥ 20% букетов студии с карточкой, ≥ 30% сканов, ≥ 5% заказов букета из страницы подарка.
