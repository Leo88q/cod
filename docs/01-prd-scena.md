# PRD «Сцена» (v0.1) — приложение «общий фильм» для двоих и семьи

Дата: 2026-11-03. Статус: черновик для обсуждения. Юрлицо: ИП (УСН 6% планируется).

## 1. Идея в одной фразе

Даришь цветы или любой повод — прикрепляешь сцену из фильма с таймкодом и личным сообщением.
Получатель отвечает своей сценой. Из сцен складывается ваш общий таймлайн — «ваш фильм».

Рабочее название: **«Сцена»**. Слоган-кандидат: «Подари не букет, а момент из фильма».

## 2. Целевая аудитория и сценарии

- Пары (RomCom-поводы: годовщины, «прости», «я тебя люблю», день рождения) — основной сегмент.
- Друзья и коллеги (благодарность, проводы, корпоративные поводы — B2B-потенциал через Flowwow corporate).
- Семьи: родители/дети, режим «для старших» — сцены из фильмов их молодости, внуки собирают подборку с голосом и фото.
- Цветочные студии — B2B-клиенты: QR-карточка «Сцена» внутри букета.

## 3. MVP (4–6 недель)

### Внутри MVP
1. Telegram-бот + Mini App. Deeplink `t.me/<bot>?startapp=<код подарка>`.
2. Создание подарка: анкета на кнопках (кому, повод, тон), подбор 5–7 сцен из каталога по тегам, личное сообщение (текст/голосовое/фото), формат «одна сцена» или «серия на N дней», отложенная дата открытия.
3. Страница получателя: анимированная открытка (фильм + таймкод + обложка), кнопка «смотреть сцену» (ссылка на легальный плеер), сообщение дарителя, ответ: сценой / реакцией / сообщением.
4. Общий таймлайн пары: сцены в хронологии с датами и поводами, заметки и фото к моментам.
5. Каталог сцен: ручной старт 200–300 записей, теги (настроение, повод, жанр, эпоха, возраст), поиск по смыслу/описанию, предложения пользователей с модерацией.
6. QR-карточка для букета + простой кабинет магазина (заказ пачки карточек, статистика сканов).
7. Витрина букетов: deep link на товар Flowwow с ref-меткой (комиссия по договору с магазином).

### Вне MVP (раунд 2)
- «Ваш фильм года»: обложка, подборка, экспорт PDF/видео, печатная книга.
- Эстафета сцен (цепочка на карте), маршруты по местам съёмок, «запах и ужин» к сцене.
- Раздел «для старших» с отдельной подборкой и семейным таймлайном.
- Второй клиент под MAX (тот же бэкенд).

## 4. Монетизация и юнит-экономика

| Модель | Механика | Экономика (оценка) |
|---|---|---|
| QR-карточка в букет (B2B) | Студия вкладывает карточку с QR в букет; получатель сканирует → страница сцены. Оплата: пачки карточек по 30–100 ₽/шт или подписка ~990 ₽/мес + кабинет | При 16 000 магазинов на Flowwow даже 1% проникновения = 160 магазинов × 30 карточек/мес × 50 ₽ = 240 тыс ₽/мес |
| Комиссия с заказа букета (CPS) | Заказ уходит на Flowwow **по прямой ссылке магазина** → комиссия площадки 0% (только ~3% эквайринг), магазин платит нам 10–15% по агентскому договору | Букет 3 000 ₽ → 300–450 ₽ нам; 100 заказов/день = 30–45 тыс ₽/день |
| Премиум-оформление | Платные темы открыток, «ваш фильм» (PDF/видео/книга) | 199–999 ₽ за цифровое, 1 990–4 990 ₽ за печатное; маржа высокая |
| Подписка | Семейный таймлайн, напоминания дат, расширенный каталог | 199–399 ₽/мес |

Источники цифр по Flowwow: комиссия 5–23% + ~3% эквайринг + 3% кэшбэк; zero-commission по прямым ссылкам магазинов (см. `docs/02-flowwow-playbook.md`).

**Важно**: не перепродаём букет «через себя» — суммарная комиссия Flowwow до ~29% съест маржу. Работаем по схеме «прямая ссылка магазина + наша комиссия с магазина».

## 5. Юридика (обязательный чеклист до платного запуска)

- **Авторское право**: показываем только название, год, таймкод и наше описание сцены. Не храним и не показываем видео, не цитируем реплики дословно. Для каждой записи в каталоге — поля `source` и `source_license`.
- **152-ФЗ**: телефоны/имена получателей, голосовые сообщения — персональные данные. Нужны: согласие при создании подарка, политика обработки ПДн на сайте, уведомление Роскомнадзора (оператор ПДн), договоры с магазинами (поручение на обработку).
- **Договоры с магазинами**: агентский договор/оферта на комиссию 10–15% и продажу карточек; ИП на УСН 6% «доходы».
- **Эквайринг**: ЮKassa или Точка для приёма оплаты подписок/карточек.
- Консультация юриста по авторскому праву перед платным запуском — заложить в бюджет.

## 6. Риски и митигации

| Риск | Митигация |
|---|---|
| Flowwow/Yandex запустят похожую фичу в букетах | Наш отрыв — «ответ сценой» + таймлайн, а не разовая открытка; работаем напрямую со студиями, а не через платформу |
| Нет публичного buyer-API у Flowwow | Deep links + прямые ссылки магазинов; заказ «в один клик» — редирект, не API |
| Таймкоды расходятся между сервисами/версиями фильма | В записи: сервис, версия, дата ручной проверки (`verified`, `verified_at`) |
| Низкий охват трафиком как агрегатора | Старт с B2B-карточек (канал дистрибуции уже в букете), CPS — поверх |
| Конкуренция «Яндекс Цветы» (запущены в 2026) | Не конкурируем в доставке напрямую; мы — смысловой слой поверх любого агрегатора |

## 7. Roadmap и KPI

- **Недели 1–2**: скелет (бот + Mini App + API), каталог 200 сцен ручной, схема БД.
- **Недели 3–4**: страница получателя, ответ сценой, таймлайн; пилотные карточки (100 шт.) в 5–10 студиях одного города.
- **Недели 5–6**: витрина букетов через deep links Flowwow, договоры с пилотными магазинами, аналитика.
- **KPI MVP**: 500 созданных подарков, 30% открытий по QR, 10% ответов сценой, 5 платящих магазинов, конверсия в заказ букета из страницы подарка ≥ 3%.

## 8. Открытые вопросы

1. Проверить руками: есть ли у Кинопоиска/Иви/Okko публичный параметр старта с таймкода (иначе показываем «перемотайте на 1:23:45» + название сервиса).
2. Уточнить у Flowwow (partner@flowwow.com / partners@flowwow.ru): условия агентских прямых ссылок и можно ли нам как партнёру-агрегатору получать комиссию официально.
3. Выбор города пилота (Москва — дорого и конкурентно; регион — дешевле вход, ниже комиссии площадок).
4. Нужен ли отдельный брендинг карточки под конкретную студию (co-branding) — решаем с первыми пилотами.
