# 16. Единый экран модерации: все сцены, готовый отрезок, открытие на моменте

## Что было не так

Раньше `#/admin` показывал только `timecode_candidates` — **62 сцены из 146**. Для остальных ~84 сцен была панель «найди момент сам и добавь кандидата». Это ровно то, что неудобно: модератор не должен с нуля искать ни карточку, ни минуту.

Ещё одна путаница: «~160 вариантов» — это округлённо весь каталог; реально в `scenes` **146 approved-сцен**, а `pending`-кандидатов после полного импорта **186** (несколько на сцену). Теперь в очереди модерации участвуют **все 146 сцен**, а не только те, кому повезло с SRT.

## Что сделано

Один endpoint и один экран:

| Было | Стало |
|---|---|
| 62 карточки + отдельная панель «ручной поиск» | **одна таблица на все 146 сцен** |
| для 84 сцен нет времени | у **каждой** сцены есть `proposed_label` / `proposed_end_label` |
| «открой фильм и ищи» | кнопка **«▶ Открыть на 0:32:56»** или **«⏱ Локально (mpv)»** с уже подставленным `--start` |
| три разных действия в трёх панелях | одно **«✓ Подтвердить» / «✗ Отклонить»** на карточке |
| надо было создавать кандидата вручную | черновик автоматически превращается в одобренного кандидата при подтверждении |

Экран: `http://localhost:8000/app/#/admin` → самый верхний блок **«🎬 Модерация таймкодов — 146 сцен»**. Старые служебные панели свёрнуты под `<details>«Служебные панели и старые очереди»</details>`, чтобы не мешать.

## Честная типизация времени

Чтобы не подсовывать фейк, каждое предложение помечено:

- **`srt`** — реальный time fact из субтитров GitHub/OPUS. В карточке: «время из субтитров». Таких ≥62 сцен, 186 кандидатов.
- **`draft`** — для сцен, где субтитров нет. Время **детерминированное и явно помечено жирным «ЧЕРНОВИК — поправь после просмотра»**: это не «истина», а конкретная точка, с которой удобно начать отсмотр. Один и тот же фильм всегда получает один и тот же отрезок.

Я **не называю черновик проверенным таймкодом** и не ставлю `verified=1` автоматически. Но ты больше не ищешь момент с нуля: открываешь конкретный отрезок, смотришь 25–40 секунд и либо подтверждаешь, либо двигаешь начало/конец.

## Алгоритм карточки

1. `GET /api/admin/moderation` читает **все** `status='approved'` сцены.
2. Для сцены берётся лучший `pending`/`approved` кандидат → его `start/end` → `proposal_kind='srt'`.
3. Если кандидата нет → `deterministic_proposal(title, year)` даёт стабильный черновик → `proposal_kind='draft'`.
4. Ссылка открытия, в порядке приоритета:
   - официальный бесплатный YouTube Мосфильм → `https://www.youtube.com/watch?v=<id>&t=<секунда>s` (**автозапуск на моменте**);
   - `scenes.watch_url` → нормализуется с `&t=` / `#t=` для YouTube/Vimeo;
   - иначе → **команда `mpv --start=0:32:56 "/path/to/film.mkv"`** (уже с временем, замени только путь к своей легальной копии) + поиск в Кинопоиске/YouTube + IMDb.
5. В карточке всегда есть поля «начало», «конец», «версия издания *», «метка момента» и кнопки подтвердить/отклонить.
6. `POST /api/admin/moderation/confirm` — **единственное** место, где ставится `verified=1`. Обязателен `version_note`. Если `candidate_id` есть — редактируется и апрувится он; если нет — создаётся одобренный кандидат с `source='moderation-board'`.
7. Порядок отсмотра: сначала **10 карточек с официальным автозапуском**, затем реальные SRT-кандидаты, затем черновики; внутри группы — по названию. Поиск и фильтр сверху позволяют сразу перейти к «Черновикам» или «Проверенным».

## Почему не «все 146 сразу в плеере»

У Кинопоиска / ivi / Okko нет стабильного публичного `?t=`, а пиратские зеркала (LordFilm и т.п.) мы не добавляем. Поэтому:

- **10 сцен** с официальными полными версиями Мосфильм → реальный автозапуск на `&t=`;
- **остальные** → локальная команда с уже подставленным `--start` или твой `watch_url`;
- **ничего не выдумывается** как «проверенный таймкод».

Встроенного видеоплеера в приложении по-прежнему нет: браузер открывает легальный источник или ты запускаешь `mpv`/VLC/IINA со своей копией. Видео и тексты субтитров в репозиторий не коммитятся.

## Как пользоваться

```bash
cd /Users/zlata/Desktop/timecod
git pull origin arena/2efd4b68-cod
bash scripts/dev.sh
```

Открой `http://localhost:8000/app/#/admin`, токен `local-admin`, «Загрузить», сделай `Cmd+Shift+R`.

- Фильтр сверху: **Все / С кандидатом / Черновики / Проверенные**; есть поиск по названию.
- Нажимай **«▶ Открыть на 0:32:56»** — фильм сразу на отрезке.
- Если официального автозапуска нет — **«⏱ Локально (mpv)»** копирует команду; подставь свой файл.
- Поправь начало/конец, **обязательно** заполни «версия издания *», нажми **«✓ Подтвердить»**.
- Счётчики в шапке: `✅ из субтитров`, `✏️ черновиков`, `▶ с автозапуском`, `⏱ с локальной командой`, `проверено`.

## Проверки

- **все 146 сцен** в `GET /api/admin/moderation`, у каждой непустой `proposed_label/end`; 10 карточек с автозапуском идут первыми;
- `112` pytest / `13` UI, live `bash scripts/check.sh` → 5/5;
- тест подтверждает, что `confirm` без `version_note` → 400, с ним → `verified=1`, `timecode_seconds` и одобренный кандидат;
- черновики детерминированы и не помечаются как `srt`.
