# 07. Как работает услуга «Сцена» целиком (end-to-end) и что есть в приложении

## Пользовательский путь

1. **Точка входа** — Telegram-бот (`/start`) или лендинг `/` (там «🎞 сцена дня» из `GET /api/scenes/daily`). Бот открывает Mini App (`/app/`), также можно зайти по QR-карточке из цветочного магазина (`/card/{code}` → редирект на создание подарка с привязанной карточкой).
2. **Выбор сцены** (`#/catalog`): поиск по смыслу (`POST /api/scenes/semantic`, TF-IDF), фильтры-поводы/настроения/жанр/эпоха/возраст (`GET /api/scenes/meta` строит категории), «✓ только проверенные», «⏱ с таймкодом», закладки, кураторские подборки (`GET /api/lists`), сортировки; фильтры шарятся ссылкой (hash URL).
3. **Выбор момента** — у сцены может быть несколько одобренных моментов-отрезков (`GET /api/scenes/{id}/moments`): чипы `⏱ 0:50:19–0:50:56 · «момент, где…»` (метка нашими словами). Таймкод — всегда **отрезок** (начало–конец), а не точка: из субтитров берётся start/end блока и доклеивается до клипа 25–75 сек.
4. **Создание подарка** (`POST /api/gifts`): получатель, город, повод, тон, сообщение текстом / **голосовым** (запись) / фото, тема открытки (cinema/retro/neon + premium paper), отложенное открытие `open_at`, формат single/series. Таймкод **фиксируется снапшотом** в `gift_scenes` — открытка неизменна. Ответ: ссылка `/g/{id}` + deeplink бота + QR.
5. **Получение** (`/g/{id}`): если `open_at` в будущем — замок с обратным отсчётом; при первом открытии — **конфетти**, дарителю уходит уведомление `gift_opened`. На карточке: фильм, год, **⏱ отрезок**, наше описание, кнопки легальных плееров (`watch_links`) + «скопировать таймкод».
6. **Ответ получателя**: реакция-эмодзи, текст, или **своей сценой** — и общий таймлайн «ваш фильм» (`/timeline`, заметки, `GET /api/film/{tg}` + экспорт HTML для premium).
7. **Букет к подарку**: каталог букетов по городу получателя (`GET /api/bouquets?city=`), заказ через партнёрскую ссылку Flowwow (`ref=scena_…`, комиссия магазину 0%, нам агентское 10–15%), редирект `/go` 307, подтверждение заказа магазином (`POST /api/shops/{id}/orders/confirm`, админка магазина видит комиссию).
8. **QR-карточки для студий**: магазин покупает pack (50 ₽/шт от 100) или по подписке 990 ₽/мес; выпуск карточек, статистика, **печатный макет A6** (`GET /api/cards/{code}/preview`), скан → `/card/{code}`.

## Как устроены таймкоды (главное)

- Источник: OpenSubtitles/OPUS (ODC-BY) и др. — см. `docs/06-timecode-sources.md`. **Текст реплик не храним**: только факт отрезка времени + sha1 + source/license.
- Авто-пайплайн `scripts/fetch_timecodes.py`: семантический матчинг по смыслу (RU TF-IDF+стемминг; EN keywords) + **консенсус** нескольких версий субтитров (±10 сек) → `confidence/auto` → `POST /api/admin/timecodes/bulk-approve` авто-ставит `verified=1`; остальное — ручная очередь в `#/admin` с меткой момента нашими словами.
- Таймкод привязан к версии издания (`service` + `version_note`); в подарке — снапшот навсегда.

## Инвентарь фичей приложения

- Mini App: каталог+фильтры+семантика+подборки+закладки, создание подарка (текст/голос/фото/тема/отложенное открытие/серии), просмотр открытки (конфетти, таймлайн, ответы, заметки), таймлайн «ваш фильм» + экспорт, важные даты + напоминания + **.ics**, букеты и заказы, кабинет студии, админка (модерация сцен, очередь таймкодов, статистика), оплата (ЮKassa/dev).
- API: см. README «Основные API» + `GET /api/scenes/meta`, `POST /api/scenes/semantic`, `GET /api/scenes/daily`, `GET /api/scenes/{id}/moments`, `GET /api/lists`, `POST /api/admin/timecodes/bulk-approve`, `GET /api/dates/{tg}/ics`, `GET /api/cards/{code}/preview`, `GET /api/users/me`, `/api/cities`, `/api/shops/{id}/orders(+confirm)`.
- Бот: webhook, deeplink `?startapp=g_{code}`, очередь уведомлений (напоминания о датах, `gift_opened`).
- Право: 152-ФЗ (согласие при создании, `consents`), только факты title+year+таймкод, легальные плееры, per-record source/license.
