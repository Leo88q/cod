# 15. Как открывать фильм сразу на нужном моменте для модерации

## Сначала про «лорд фильм» и платные сервисы

Добавлять LordFilm / «зеркала» / неофициальные онлайн-плееры в продукт **не будем**: это нелегальные источники, а вся схема модерации построена на том, что таймкод подтверждается после просмотра в **легальном** плеере. Обходить оплату Кинопоиска / ivi / Okko тоже не задача проекта: подписка, прокат, диск, эфир или официальная бесплатная публикация студии — всё это легальные варианты.

Проблема, которую реально стоит решить: модератору неудобно сначала искать фильм, потом вручную перематывать на `0:47:12`. Ниже алгоритм, который убирает эти шаги, не нарушая юридических рамок.

## Алгоритм

Для каждого `pending`-кандидата:

1. **Определяем целевую секунду.** `timecode_seconds` (или парсим `timecode_label` вида `0:47:12`). Конец отрезка `timecode_end_seconds` показываем рядом, но deep link ведёт на начало.
2. **Идентифицируем фильм.** Ключ `«название|год»` + `imdb_id` из `imdb_map_full.json`. Год обязателен: «Начало» 1970 и 2010 — разные фильмы.
3. **Ищем легальную бесплатную полную версию** в `data/timecode_library/official_free_videos.json`. Это кураторский список официальных загрузок «Киноконцерна Мосфильм» на YouTube/RuTube и официальных страниц студии. Видео и тексты в репозиторий не коммитимся — только `video_id` и ссылки.
4. **Генерируем deep link на момент.** Для YouTube: `https://www.youtube.com/watch?v=<id>&t=<секунда>s`. Пример для «Иронии судьбы» на `0:47:12`: `https://www.youtube.com/watch?v=y5CQr_D-NZg&t=2832s`. Кнопка «▶ youtube_mosfilm · 0:47:12» открывается сразу на моменте.
5. **Всегда добавляем независимый от подписок путь** — локальную легальную копию. UI копирует готовую команду:
   ```bash
   mpv --start=0:47:12 "/path/to/film.mkv"
   vlc --start-time=1976 "/path/to/film.mkv"
   iina --start-time=1976 "/path/to/film.mkv"
   ```
   Оператор заменяет `/path/to/film.mkv` на свой файл. IINA — для macOS.
6. **Нормализуем уже вставленный `watch_url`.** Если оператор дал ссылку YouTube/Vimeo, бэкенд сам убирает старый `t` и добавляет `&t=1976s` / `#t=1976s`. Для Okko/ivi/Кинопоиска стабильного публичного deep link нет — оставляем ссылку как есть и показываем «перемотай вручную».
7. **Fallback-поиск.** Официальный канал Мосфильм → YouTube/VK Видео → Кинопоиск/ivi/Okko (могут требовать подписку) → IMDb/TMDB для сверки года и издания.
8. **Ранжируем.** `official_deep` (приоритет 1) → `official_page` / `manual_deep` (2) → `local` (3) → `official_search` (4) → `search` (5) → `identify` (6). В карточке админки показываются первые 5 ссылок + кнопка локальной команды.
9. **Для сцен без SRT-кандидата — ручное создание.** Панель «🎬 Легальные полные версии для ручного поиска момента» показывает `moderation.targets[]`: открываешь официальный фильм, находишь момент, вписываешь начало/конец/версию/метку и жмёшь «＋ Добавить момент». `POST /api/admin/timecodes/manual` кладёт `pending`-кандидата в ту же очередь; дальше обычное «✓ Подтвердить».
10. **Не подтверждаем автоматически.** Любая ссылка — только подсказка. `verified=1` по-прежнему ставится кнопкой «✓ Подтвердить», а `version_note` обязателен: реставрация 4K, ТВ-монтаж и двухсерийная версия могут сдвинуть минуты.

|---|---|
| `data/timecode_library/official_free_videos.json` | 12 кураторских записей, 10 сцен с YouTube-deep-link, официальные страницы/каналы, `evidence_url`, `version_hint`, флаг `verified_by_human: false` |
| `app/moderation_links.py` | `build_moderation_links()`, `normalize_watch_url()`, `local_commands()`, `moderation_coverage()` |
| `GET /api/admin/timecodes` | у каждого кандидата появилось поле `moderation_links[]` |
| `GET /api/admin/timecode-library` | поле `moderation` со счётчиками и `targets[]` — сцены, где официальная полная версия есть, а SRT-кандидата может не быть |
| `POST /api/admin/timecodes/manual` | оператор сам нашёл момент в легальной версии и создаёт `pending`-кандидата (обязательны таймкод и `version_note`); `verified=1` не ставится |
| `#/admin` | кнопки «▶ youtube_mosfilm · 0:47:12», «⏱ Локально (mpv)», «🔍 Мосфильм», предупреждение про издание, строка в панели «📚 Библиотека таймкодов» и панель «🎬 Легальные полные версии для ручного поиска момента» с формой добавления момента |
| `scripts/resolve_official_videos.py` | опциональный помощник на Mac через `yt-dlp`: ищет кандидатов, но **не добавляет их автоматически** |

## Кураторский список (best-effort)

Покрыты в первую очередь советские фильмы, которых нет в GitHub-SRT зеркалах: «Ирония судьбы», «Иван Васильевич меняет профессию», «Москва слезам не верит», «Служебный роман», «Операция «Ы»», «Любовь и голуби», «Кин-дза-дза!», «Девчата», «Гараж», «Война и мир» (часть 1), плюс официальная страница «Белого солнца пустыни».

**Важно:** `video_id` взяты из описаний официальных трейлеров/фрагментов и страниц Мосфильм, но человеком ещё не сверены. Поэтому в JSON стоит `verified_by_human: false`, а в UI — предупреждение. Модератор должен убедиться, что:

- канал действительно официальный;
- это полный фильм, а не трейлер/фрагмент;
- совпадает часть/серия (особенно «Война и мир», «Москва слезам не верит», «Служебный роман», «Кин-дза-дза!»);
- таймкод соответствует именно этому изданию — и записать его в `version_note`.

Пример проверки: открыть `https://www.youtube.com/watch?v=y5CQr_D-NZg&t=1976s`, посмотреть 25 секунд, поправить начало/конец при смещении, написать `«Мосфильм, реставрация, YouTube»` и нажать «✓ Подтвердить».

## Как пополнять список легально

```bash
python3 -m pip install yt-dlp   # только на локальной машине
.venv/bin/python scripts/resolve_official_videos.py \
  --key "Название фильма|год" \
  --imdb-id tt1234567 \
  --query "Название фильма полный фильм"
```

Скрипт печатает черновики с `video_id`, названием и каналом. Дальше — **ручная проверка** официального канала/страницы и только потом добавление строки в `official_free_videos.json`. Никакого автоматического импорта пиратских результатов, iframe-ссылок или обхода региональных ограничений.

Альтернативные легальные источники, которые можно добавить тем же алгоритмом: официальные каналы «Ленфильм», «Союзмультфильм», киностудии им. Горького, Internet Archive для общественного достояния, официальные трейлеры/клипы (для идентификации, но **не** для проверки полного таймкода). CineSubBench и HF-корпуса остаются только источниками субтитров, а не плеерами.

## Юридические оговорки

- Бесплатная официальная публикация ≠ общественное достояние. Права на фильм остаются у правообладателя; перед коммерческим запуском нужна юридическая проверка конкретных ссылок.
- Мы не встраиваем плеер, не скачиваем видео, не храним тексты субтитров и не генерируем ссылки на нелегальные зеркала.
- Кинопоиск/ivi/Okko могут требовать подписку — это ожидаемо; локальная копия и официальные бесплатные загрузки дают путь без неё.
- `watch_links` по-прежнему поисковые; автоматический `?t=` делается только там, где провайдер имеет стабильный публичный формат (YouTube, Vimeo).
